Git и GitHub
Git - система контроля версий, которая позволяет отслеживать изменения в проекте
GitHub - сервис для хранения Git-репозиториев и совместной работы с ними

git diff - сравнивает рабочую директорию с областью подготовленных изменений. Показывает изменения, которые еще не добавлены командой git add
Git diff --staged - сравнивает область подготовленных изменений с последним коммитом . Показывает изменения, которые уже добавлены командой git add и попадут в следующий коммит
