## Сравнение версий и поиск изменений

git log --oneline --stat — показывает историю коммитов в кратком виде и статистику изменений файлов.

git diff HEAD~2 HEAD -- lab03/calc.py — сравнивает текущую версию calc.py с версией два коммита назад. В результате видно, что были добавлены операции вычитания и умножения.

git show HEAD — показывает информацию о последнем коммите и изменения, внесённые в нём.

git log -S'a*b' --oneline -- lab03/calc.py — позволяет найти коммит, в котором появилась строка с умножением. Это коммит 244faf5 «Добавлено умножение».

git blame lab03/calc.py — показывает, в каком коммите и кем была добавлена каждая строка файла.
## Отмена ошибочного коммита

git revert — не удаляет ошибочный коммит из истории, а создаёт новый коммит, который отменяет его изменения.

git reset --hard — перемещает указатель ветки на другой коммит и удаляет последующие изменения из рабочей папки.

В опубликованной истории безопаснее использовать git revert, потому что он не переписывает существующую историю и не удаляет уже опубликованные коммиты.
